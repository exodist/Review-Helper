# AI_DOCS

Working documents an agent needs for upcoming development: a design or plan
for work not yet built, or context a later task must read before it starts.
Remove a document once the work it serves is done.

Not here: review transcripts, review-cycle records, decision walks, or other
history. Git keeps history; current decisions are in `RULINGS.md` and
deferred work in `PLANNED_TODO.md`.
